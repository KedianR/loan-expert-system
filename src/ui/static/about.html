About this system

Deployed demo: the audit log is temporary and decision IDs are not globally unique.

What it is

LoanCheck is an academic prototype of a rule-based expert system for assessing eligibility for an unsecured personal loan denominated in Indian Rupees (INR). Production (IF-THEN) rules evaluated by a forward-chaining engine drive every decision; a lightweight ML classifier is built only as a comparison baseline. All policy thresholds, rate bands, and fee schedules are illustrative values stored in params/params.toml and are not derived from any real lender's credit policy. Every dataset used is either synthetic or publicly available. This is not a real lending decision.

Three possible decisions

ELIGIBLE

Eligible

The application passes all validation and knockout checks, satisfies existing obligations and credit criteria, and has sufficient repayment capacity. A recommended loan amount and indicative interest band are returned along with the full deterministic trace.

INELIGIBLE

Ineligible

One or more knockout or policy rules fired — including age under 18 (K01), non-resident status (K02), severe recent delinquency (K03), bankruptcy (K04), income below ₹15,000 (K05), requested tenure over 60 months (K06), missing consent or invalid loan parameters (V02–V04), existing obligations ratio exceeding 50% (E01), or calculated repayment capacity falling below the ₹50,000 minimum loan amount (A03).

REFER

Refer

The application requires manual underwriter review due to policy-defined referral conditions: no credit history or unscoreable thin file (R01), more than 5 credit enquiries in the last 6 months (R02), employment type recorded as 'other' (R03), or a required application fact is missing (V01).

Policy values

Policy thresholds are kept in params/params.toml and referenced by name. No policy number appears directly in source code or rule text — every threshold, interest band, and fee is read from the parameter file. This design ensures that changes propagate cleanly to every rule and calculation.

Limits

  • Mapping effects: Input fields are mapped to internal predicates; small differences in how an applicant describes their situation can shift the outcome.
  • Synthetic data: All training and evaluation datasets are synthetic or publicly available. Distributions may not reflect real loan applicant populations.
  • No authentication: This prototype has no login, session management, or access control. It must not be used with real personal data.
  • Illustrative policy: Thresholds and rate bands are chosen to demonstrate the system, not to reflect any lender's actual credit policy.
  • No real lending decision: Output from this system has no legal or financial standing and should never be used to make or inform a real credit decision.
  • Prototype stability: The rule set, parameter values, and ML model may change between versions. Audit replay is supported but results are not guaranteed to be stable across major version updates.
