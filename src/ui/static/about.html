About This System

What this is

This is an academic prototype of a rule-based loan eligibility expert system for unsecured personal loans in INR. It is built for a coursework project and uses illustrative policy values and synthetic or publicly available data only. It is not a real lending system and must not be used for any real credit decision.

Three possible decisions

ELIGIBLE
The application meets all policy rules. A recommended loan amount and interest band are shown. This is a prototype result, not a real offer.
REFER
The application cannot be decided automatically and is referred to a human reviewer for further assessment.
INELIGIBLE
The application does not meet one or more policy rules. The specific reasons are shown.

Policy values

All thresholds, rates and limits used by the system are illustrative (D-02 in the design log). They are stored in params/params.toml and are not real credit policy.

Data

The ML baseline is trained on a mapped version of the Home Credit Default Risk dataset (D2) and a synthetic dataset (D3). No real personal data is used or stored. Raw data files are never committed to the repository.

Limits

  • Policy values are illustrative only.
  • Datasets are mapped or synthetic; this is a worked example, not a production credit policy.
  • D2 results reflect Home Credit mapping effects and 1.68% approval rate.
  • D3 uses synthetic protected attributes drawn independently of other fields.
  • No authentication, no real storage, no real grievance mechanism.
